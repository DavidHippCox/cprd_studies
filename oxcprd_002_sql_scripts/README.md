# OXCPRD_002

## Summary

exporting CPRD AURUM data (primary care only) for Msc project titled: 
Primary Care Assessment of Alcohol Use and Interventions Before Alcohol-Related Liver Disease: A Population-Based Retrospective Cohort Study Using CPRD Aurum. 


## Order to Run Scripts

Run the scripts in the following order:

1. `extract/identification/aurum_import_codelists.sql`
2. `extract/identification/aurum_extract_arld.sql`
3. `extract/identification/export_alcohol_unit_tables.sql`
4. `extract/identification/import_alcohol_unit_tables.sql`
