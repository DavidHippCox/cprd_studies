# Aurum_alcohol


## Summary

Search all bmi, weight and height observations in CPRD Aurum for appropriate numunitid and medocideid combinations. Then find patids with high alcohol consumption and 'AUD' across CPRD and HES APC and HES OP. 

## Order to Run Scripts

Run the scripts in the following order:

1. aurum_alcohol\import_codelists.sql
2. aurum_alcohol\alcohol_observations.sql
3. aurum_alcohol\cprd_alcohol_units.sql
4. aurum_alcohol\aurum_aud.sql
